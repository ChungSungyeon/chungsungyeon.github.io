# Chirpy 포스트 편집기

왼쪽에서 마크다운을 쓰면 오른쪽에 실제 Jekyll 빌드 결과가 뜨는 개인용 편집기.

```
tools/editor/
├── app.py             # FastAPI 백엔드 + Jekyll 프록시
├── static/index.html  # UI
├── requirements.txt
└── start.sh
```

---

## 실행

```bash
tools/editor/.venv/bin/python tools/editor/app.py
```

PORTS 탭에서 **5000번 포트**를 열고 `/app` 으로 접속 → 상단 **Jekyll [시작]** (첫 빌드 20~40초).
Jekyll(4000)은 편집기가 프록시하므로 따로 열 필요 없다.

`.venv` 가 없으면 (Codespace 신규 생성·리빌드 직후) 한 번만:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
$HOME/.local/bin/uv venv --python 3.12 tools/editor/.venv
$HOME/.local/bin/uv pip install --python tools/editor/.venv/bin/python -r tools/editor/requirements.txt
```

pip 이 있는 환경이면 `bash tools/editor/start.sh` 로 대체 가능.

환경변수: `EDITOR_PORT`(5000), `JEKYLL_PORT`(4000), `JEKYLL_INCREMENTAL=1`(증분 빌드)

## 상단 바

| 버튼             | 동작                                            |
| ---------------- | ----------------------------------------------- |
| 새 글            | 날짜 + slug 입력 → md 파일과 자산 폴더 2개 생성 |
| 저장             | 저장 → 재빌드 대기 → 미리보기 갱신 (`Ctrl+S`)   |
| 발행             | `_drafts` → `_posts` 이동                       |
| 삭제             | md 파일 + 자산 폴더 삭제                        |
| Jekyll 시작/정지 | 미리보기 서버                                   |
| 로그             | 빌드 로그 · 캐시 비우고 재시작                  |
| Clean assets     | 본문에서 안 쓰는 자산 파일 정리                 |
| Git              | 커밋 + push                                     |

## 기능

### 자동 폴더 생성

**새 글** 에서 날짜와 slug 를 넣으면 세 가지가 한 번에 만들어진다.

```
_posts/2026-06-26-accounting-management-review.md
assets/img/2026-06-26-accounting-management-review/
assets/files/2026-06-26-accounting-management-review/
```

front matter 의 `media_subpath` 도 채워지므로 본문에는 파일명만 쓰면 된다.

자산 폴더 위치는 `app.py` 상단 두 줄로 바꾼다. URL·front matter·UI 가 전부 여기서 따라간다.

```python
IMG_ROOT  = REPO / "assets" / "img"
FILE_ROOT = REPO / "assets" / "files"
```

### 미리보기

`Ctrl+S` 또는 **저장 + 새로고침** 을 눌렀을 때만 저장·재빌드된다 (자동 저장 없음).
빌드 완료 시점을 감지해 갱신하며 스크롤 위치는 유지된다. 저장부터 반영까지 1~3초.

저장 안 된 변경이 있으면 상태바에 `저장 안 됨 — Ctrl+S`.

### 삽입

| 버튼                          | 결과                                                              |
| ----------------------------- | ----------------------------------------------------------------- |
| 이미지                        | `![alt](file.png){: w="800" }` + 아래줄 `_설명_`                  |
| 표                            | 아래 참조                                                         |
| 첨부                          | `<a href="/assets/files/<id>/file.pdf" download>원본이름.pdf</a>` |
| 링크                          | `[텍스트](URL)`                                                   |
| 여백                          | `&nbsp;` 한 줄                                                    |
| tip / info / warning / danger | `> 내용` + `{: .prompt-tip }`                                     |

- 이미지·첨부는 드래그&드롭 또는 파일 선택 → 해당 포스트 폴더에 자동 저장.
- 편집기 본문에 직접 드롭해도 된다 (확장자로 판별).
- 업로드 시 최대 폭 1600px 리사이즈 + 압축. WebP 변환, 파일명 ASCII 변환은 선택.

### 표

빈 칸으로 시작하며 헤더 모드를 네 가지 중 고른다.

| 모드        | 출력                         |
| ----------- | ---------------------------- |
| 없음 (기본) | 구분선 없는 마크다운 표      |
| 1열이 헤더  | HTML 표 (`<th scope="row">`) |
| 1행이 헤더  | 마크다운 표 (`\|---\|---\|`) |
| 둘 다       | HTML 표                      |

마크다운 표는 1행 헤더만 지원하므로 1열 헤더는 HTML 로 출력한다.
Chirpy 가 HTML 표에도 테마 스타일을 입히므로 겉보기는 같다.

행·열 추가·삭제, 엑셀에서 탭 구분 붙여넣기 지원.

### 줄바꿈 자동화

툴바 **"줄바꿈 자동"** 체크박스로 켜고 끈다.

| 상황                        | 동작                                  |
| --------------------------- | ------------------------------------- |
| 글자 있는 줄에서 Enter      | 줄 끝에 스페이스 2칸 + 개행           |
| 빈 줄에서 Enter             | `&nbsp;` 여백 삽입                    |
| 리스트에서 Enter            | 스페이스 2칸 + 다음 마커 (`- `, `2.`) |
| 빈 리스트 항목에서 Enter    | 리스트 탈출                           |
| `>` 안에서 Enter            | `> ` 이어쓰기                         |
| 제목 · `{: ...}` · `_캡션_` | 스페이스 없이 개행                    |
| 코드블록 · 표 안            | 자동화 끔                             |
| Shift+Enter                 | 언제나 순수 개행                      |

### Front matter

title / description / 날짜 / 카테고리 / 태그 / 대표이미지 / toc / pin / math / mermaid 를 폼으로 편집.
저장 시 Chirpy 관례 순서와 스타일로 다시 써진다.

- 카테고리·태그는 기존 포스트에서 수집해 자동완성한다. 칩 순서가 곧 카테고리 계층.
- **alt** 는 이미지가 안 뜰 때 대신 읽히는 설명. 그림에 뭐가 보이는지 적는다 (예: `회계관리2급 성적표`).

### 초안

새 글 만들 때 "초안으로 시작" 을 켜면 `_drafts/` 에 생성된다. 배포되지 않고 미리보기는 정상 동작한다.
**발행** 을 누르면 `_posts/` 로 옮기고, 날짜가 바뀌었으면 자산 폴더 이름과 본문 경로까지 함께 고친다.

`_drafts/` 도 커밋 대상이다. 저장소가 public 이면 초안도 공개된다.

### Clean assets

본문에서 참조하지 않는 자산 파일을 찾아 선택 삭제한다. 필수는 아니고, 이미지를 여러 번
갈아끼운 글을 마무리할 때 쓴다. 파일명이 문서 어디에든 등장하면 사용 중으로 판단한다.

삭제 범위는 현재 포스트의 자산 폴더 2개로 제한된다.

### Git

변경 파일을 확인하고 커밋·푸시한다. 커밋 메시지 기본값은 글 제목이며 자유롭게 고치면 된다.

| `Ctrl+S`      | 저장 + 재빌드 + 미리보기 갱신 |

## 문제 해결

| 증상                                      | 조치                                         |
| ----------------------------------------- | -------------------------------------------- |
| 미리보기가 안 뜬다                        | Jekyll [시작] → **로그** 에서 빌드 오류 확인 |
| 목록에 지운 글이 남거나 새 글이 안 보인다 | **로그 → 캐시 비우고 재시작**                |
| 블로그에 반영이 안 된다                   | **Git** 에서 push 했는지 확인                |
| `.venv` 가 없다                           | 위 "실행" 의 uv 명령 3줄 재실행              |

- 저장하면 원본 `.md` 를 덮어쓴다. 되돌리기는 Git.
- `tools/` 는 `_config.yml` 의 `exclude` 라 블로그에 배포되지 않는다.
- Codespace 는 30일 미사용 시 삭제된다. push 안 한 글은 함께 사라진다.
